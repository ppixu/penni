# Security policy

Penni is in **beta**. Security reports are welcome and are handled on a best-effort basis.

## Reporting a vulnerability

Please report vulnerabilities **privately**, not in public issues:

- Email <hei@penni.pro>, or
- use GitHub's private vulnerability reporting on <https://github.com/ppixu/penni> (Security tab,
  "Report a vulnerability").

Include what you found, how to reproduce it, and which version or commit you tested. Please do not
include real bookkeeping data.

We will acknowledge the report when we can, work on a fix, and credit you in the fix if you wish.
There is no bug bounty and no guaranteed response time during the beta.

## Scope notes

- The books you create are plain files on your own machine (or browser storage). Keep your own
  backups.
- Bookkeeping correctness bugs (wrong figures, numbering, VAT) are not security issues; please file
  them as normal issues.
